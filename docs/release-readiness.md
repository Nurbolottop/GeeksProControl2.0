# Готовность GeeksPro Control 2.0 к тестовому запуску

> **Статус: НЕ готово к production.** Платформа реализована и проверена
> автоматическими тестами на синтетических данных; staging подготовлен к развёртыванию,
> но **не развёрнут**. Production-запуск разрешён только после выполнения всех пунктов
> «Требует внешней проверки» и «Требует подготовки» с подписью ответственного.
> Состояние на этап 11A. Процедуры — `docs/staging-runbook.md`, перенос — `docs/migration-plan.md`.

## 2. Требует внешней проверки

Каждая проверка — на stage, `GP2_ENVIRONMENT=stage`, `TELEGRAM_OUTBOUND_MODE=allowlist`,
только тестовые аккаунты и группы.

| # | Что | Процедура | Критерий успеха |
|---|---|---|---|
| 2.1 | Telegram Bot API (тестовый бот @GeeksProAutoBot) | `TELEGRAM_TEST_CHAT_IDS` — свои id; `docker compose --profile bot up -d bot`; `/start`, все кнопки меню | Клавиатура постоянная, каждая кнопка отвечает; в журнале «Telegram-бот» — статус «Отправлено»; посторонний чат — «skipped» |
| 2.2 | Группы и темы | Тестовая супергруппа в `TELEGRAM_TEST_GROUP_IDS`, бот — админ с «Управление темами»; код в Control → `/bind КОД` → «Подтвердить» | Темы созданы один раз; «Обновить темы» не дублирует; удалённая тема создаётся заново; вступление участника отмечается по `chat_member` |
| 2.3 | Подтверждение отдела продаж | Тестовая группа продаж в `SALES_TELEGRAM_CHAT_ID`, свой id в `SALES_AGENT_TELEGRAM_IDS`; сообщение по шаблону `#оплата` | Совпадение — «Принято», заявка подтверждена; неверный город / чужой сотрудник / пересланное — не принято |
| 2.4 | JaaS: запрет входа без JWT | В консоли JaaS включить требование токена; открыть `https://8x8.vc/<AppID>/<room>` без `?jwt=` | Вход невозможен. Только после этого `JAAS_ANONYMOUS_BLOCKED_VERIFIED=1` (иначе production-вход заблокирован, `gp2.W010`) |
| 2.5 | JaaS: JWT | AppID, ключ (kid) в консоли, приватный ключ файлом вне репозитория (`chmod 600`); `VIDEO_PROVIDER=jaas`; тестовое собрание; вход кнопкой бота | Вход по одноразовому коду открывает комнату с именем участника; повторное открытие кода — 403 |
| 2.6 | Реальные вебхуки JaaS | Вебхук на `https://<stage>/video/webhook/jaas/`, секрет в `JAAS_WEBHOOK_SECRET`; провести тестовое собрание с 2 участниками | В карточке собрания — события, «Подтверждено автоматически» у вошедших по коду; неверная подпись — 401; собрание «Проведено» по событиям |
| 2.7 | Мобильное устройство | iPhone и Android, Safari и Chrome: Dashboard, проекты, Kanban, отчёты, собрания, резерв, Telegram-настройки | Нет горизонтальной прокрутки, модальные окна закрываются, формы отправляются, меню открывается |

## 4. Известные ограничения

* Пересланное **свежее** сообщение бота с одноразовой ссылкой (5 минут) владелец может
  передать сам — система проверяет связь с Telegram-аккаунтом, а не физическую личность.
* Стажёр без Telegram не получает вход на видеособрание: посещаемость — ручной отметкой.
* Размер шрифта счётчиков и заголовков таблиц — 10–11 px (решение дизайн-системы).
* Длительность присутствия — только по событиям выхода; порога «минимум минут» нет.
